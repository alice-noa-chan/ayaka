# Prepared native training kit

Ayaka source is MIT licensed; the complete license is at the kit root.
The pinned base model is google/gemma-4-E4B-it, revision
ee0ef6023621cff504d758262d4e04895a5af4a2. Its audited repository license is
Apache 2.0; original model metadata/card is included with the snapshot when
available. No user authentication tokens or Hugging Face token cache are packaged.

Authored calendar, rules, probability, multilingual mechanics, native-image and
candidate supervision is generated by the MIT-licensed Ayaka source. Natural
human-labelled rehearsal uses these CC BY 4.0 sources:

- NVIDIA HelpSteer2: https://huggingface.co/datasets/nvidia/HelpSteer2
- CommonsenseQA: https://huggingface.co/datasets/tau/commonsense_qa
- Amazon MASSIVE (Korean/Japanese): https://huggingface.co/datasets/AmazonScience/massive

Exact source revisions, provenance and retained example IDs are recorded in
bundle/model_preflight.json and the per-sample JSONL metadata. Train, router_train,
dev, calibration and test remain separate. Repeated row exposures are not distinct
examples or independent epochs. No model-generated commercial teacher target is added.

The Python runtime is a relocatable python-build-standalone distribution obtained
through Astral uv. Third-party Python/CUDA libraries retain their distribution
metadata and license files. All Python dependencies are version/hash locked in
requirements.lock.txt. The deployment target is Linux x86_64 with glibc >= 2.28,
an NVIDIA host driver compatible with CUDA 12.8, and one RTX PRO 6000 96GB.
