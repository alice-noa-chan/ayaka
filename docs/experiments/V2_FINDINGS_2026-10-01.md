# Ayaka v2 exploration findings — 2026-10-01

The bounded exploration and both candidates' independent tests are complete.
All values below are local, open measurements, not an official JevBench composite
or evidence of a Top 5 rank. Published v1 weights remain separate.

## Reproducible implementation and measurements

The H100 continuation ran source `a7fc4e5` with curriculum version 3. The later
`7742e3c` change preserves calibration measurements alongside temperatures;
an observer retained the running worker's complete reports before replacement.
It did not change fitting, inference or measured probabilities. The CPU collector
verifies split signatures, targets and case identities and hashes source reports
and adapter/head safetensors. See [machine-readable findings](results/v2-20261001.json)
and [execution audit](results/v2-20261001-audit.json).

The runtime is one NVIDIA H100 80GB, PyTorch 2.8.0+cu128, Transformers 5.17,
PEFT 0.21 and native eager BF16 greedy generation. Timings include serial
decision work; they are not optimized serving throughput or FP8/drafter timings.
Price was not measured and no monetary cost is inferred.

New checkpoints default to auto/medium. Forced on/high bypasses the direct
routing readout and preserves its 1,024-token maximum, including simple inputs.
Normal EOS can end a short solution sooner. Off never generates. Fieldwise
question/request/server/checkpoint inheritance, failures, raw EOS/fallback token
accounting, native heads/caches and legacy v1 behavior are covered by tests.

All observed containers are closed. The cumulative conservative attached-GPU
bound is **13,627 seconds (3h 47m 07s)**, below 8h. Interrupted runs, loading,
report persistence and closure margins count toward that bound.
The screen/recovery shared ceiling and each stage's cumulative ceiling are
retained rather than granting a fresh budget on every restart.

Recovery's 2,305.73 seconds are already included in the screen row and also
satisfy the shared 3,600-second recovery/reproduction ceiling. A separate fresh
GPU reproduction run was not performed. Candidate deferrals are listed above;
no unfinished result is treated as a completed comparison. The budget ledger
was reconciled locally against external closure observations; stage allocations
remain visible and the original remote reserved ledger's hash is retained in
the audit. This bound is not an invoice or consumed-reservation estimate.

Full local verification after the final code change: Ruff lint and format checks
passed, 323 tests passed, and one Beam deployment test was skipped because its
SDK is not installed. Related checks preceded each separate implementation commit.
The final report and raw checkpoint audit require no further GPU generation.

The implementation demonstrates explicit control and a reproducible comparison,
but the present procedural data is insufficient to justify publishing these SFT
weights or escalating directly to a large main training run. Gemma 12B leads the
pre-SFT screen; E4B has the stronger post-SFT dev point result and merits further
study of concise traces and routing. This screen does not rank all twelve
candidates or establish JevBench competitiveness. No final public backbone is
promoted using test outcomes.

Before deciding a main-training budget, mix license-clean natural-language direct
examples and multilingual preservation data with verified traces; add harder
counterfactual rule/distractor pairs and soft uncertainty targets; and establish
improvement on a new held-out set. The current independent test remains a reported
failure diagnosis, not a new tuning set. RL and optimized speculative decoding
remain future work rather than unmeasured benefits in this exploration.
The next calibration study must explicitly examine Noul abstention as well as
proper losses on fresh reserved data; changing these temperatures to maximize
the current test would invalidate that test's independence.
